
# ui.dropdown_item

An item in a drop-down menu.

## Instance properties

<dl>
   <dt>alignment</dt>
   <dd>
      An alignment string.
   </dd>
   <dt>font</dt>
   <dd>
      A <code>font</code> object.
   </dd>
   <dt>icon</dt>
   <dd>
      An icon to be displayed next to the drop-down item's text. This value can be a <code>raster</code>, <code>dds_resource</code>, or color. If a color is specified, the displayed icon will be a solid-color square.
   </dd>
   <dt>text</dt>
   <dd>
      The displayed text of the drop-down item.
   </dd>
   <dt>text_color</dt>
   <dd>
      The color of the drop-down item's displayed text.
   </dd>
</dl>

## Singleton methods

<dl>
   <dt>ui.dropdown_item.is(arg)</dt>
   <dd>
      Tests whether <var>arg</var> is an instance of this class. Returns a boolean.
   </dd>
</dl>
