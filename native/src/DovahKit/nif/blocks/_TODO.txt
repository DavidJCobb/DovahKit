 - Decoding Havok NIF blocks:

    - Unk_28 is a getter for the size of the struct to read
    - Unk_29 carries out the read
    - Unk_2A may be post-read code (e.g. pointer fixups)
    - Unk_2B is a getter for a pointer to the struct to read
       - ...and it may create the struct when called, too
    - Reading is basically just a blind memcpy

    - Class hierarchies:

       - hkConstraintCinfo (RTTI)
          - hkConstraintInfo? (no RTTI)
