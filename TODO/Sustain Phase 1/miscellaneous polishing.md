
# Miscellaneous polishing

## Dialogue flowchart

It'd be nice to have the same kind of dialogue flowchart as is present in the Creation Kit, but with some enhancements:

* It should be possible to right-click the connection between two topics/infos, and click "Add a bend" to add an additional bend to the connector line. This would make it easier to tailor connectors so that they don't overlap each other or other boxes in weird ways.
